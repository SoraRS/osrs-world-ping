## Project

OSRS World Ping is an independent connection monitor for Old School RuneScape, created by [SoraRS](https://github.com/SoraRS). It is not affiliated with or endorsed by Jagex.

- [Project and downloads](https://github.com/SoraRS/osrs-world-ping)
- [Report a problem](https://github.com/SoraRS/osrs-world-ping/issues)
- [Apache License 2.0](https://github.com/SoraRS/osrs-world-ping/blob/main/LICENSE) for application code and original project artwork.

## Artwork and profile icons

All artwork is bundled locally; the app does not download images at runtime. The fantasy observatory and compass/signal emblem were created for this application. Country flags and fallback activity symbols are vectors.

OSRS skill and boss sprites are third-party artwork © Jagex Ltd. They identify worlds and activities and are not covered by the project's Apache license. See [sprite sources and credits](https://github.com/SoraRS/osrs-world-ping/blob/main/src/OsrsWorldPing.Desktop/Assets/Osrs/SOURCES.md).

GitHub and Discord profile marks have their own source/license notices. See [profile icon credits](https://github.com/SoraRS/osrs-world-ping/blob/main/src/OsrsWorldPing.Desktop/Assets/Icons/SOURCES.md) and the [artwork overview](https://github.com/SoraRS/osrs-world-ping/blob/main/src/OsrsWorldPing.Desktop/Assets/README.md).
